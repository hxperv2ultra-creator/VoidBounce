# VoidBounce

Dunkles, leicht durchsichtiges Theme für LiquidBounce Nextgen (26.2), basierend auf dem offiziellen Theme.

## Installation
1. Ordner `VoidBounce` in den Themes-Ordner kopieren (`.client theme browse` öffnet ihn)
2. `.client theme set VoidBounce`

## Selbst bauen
`npm install && npm run build` – Ergebnis liegt in `dist`.
